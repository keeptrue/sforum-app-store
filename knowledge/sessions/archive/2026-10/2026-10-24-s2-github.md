# 2026-10-24 Session Handoff — S2 GitHub App

## Changed

- **config**：`GITHUB_APP_ID` / `GITHUB_APP_SLUG` / `GITHUB_WEBHOOK_SECRET` /
  `GITHUB_APP_PRIVATE_KEYS`（`kid:base64 PEM`，多 key 轮换）；四者必须同时存在。
- **GitHub 客户端**：`src/lib/github/{jwt,client}.ts`。RS256 JWT（iss/iat/exp 600s）、
  installation token 进程内缓存（到期前 60 秒刷新）、getInstallation / repositories /
  release / asset download（302 单独处理，不把 Authorization 带到 S3）。
- **webhook**：`verifyGithubSignature`（`X-Hub-Signature-256`）、`webhook_deliveries` 按
  `X-GitHub-Delivery` 幂等、路由只验签+入队（202）；坏签名 401；重复 202 duplicate。
- **队列/worker**：pg-boss（`github-webhook` / `release-sync` 队列），`src/worker.ts` 消费；
  `installation.created` 写 `github_installations`，delivery 置 `processed`。
- **安装**：`/api/github/install/start` 签名 state（10 分钟）→ GitHub App 安装页；
  `/api/github/setup` 存 installation。
- **检测**：`src/lib/detection/{manifest,zip,platform,checksums}.ts`。ZIP 用 `yauzl` 流式读，
  2048 entries / 50 MiB 上限；`buildinfo` → ELF/Mach-O 头 → 文件名；主题 `any/any`。
- **同步**：`src/lib/github/sync.ts`。一个 tag 挂 N 个 ZIP → N 个 `release_versions`；同版本改
  摘要 → `needs_attention`；checksums 交叉校验；重复同步幂等。
- **schema**：`products`、`github_installations`、`github_repos`、`repo_releases`、
  `release_versions`、`release_assets`、`webhook_deliveries`；迁移 `drizzle/0001_*.sql`。
- 测试 40 pass（13 文件）；CI 仍是 Postgres service + `bun test` + build + smoke。
- 决策：`knowledge/decisions/2026-10-24-s2-github-and-zip.md`。
