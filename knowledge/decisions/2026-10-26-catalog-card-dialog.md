# 商城目录：卡片网格与 body 级详情弹窗

Status: accepted
Date: 2026-10-26
Related: `2026-10-24-s5-plugin-admin-page.md`（手写 ESM 管理页）、
`sessions/2026-10-26-catalog-card-dialog-handoff.md`（证据与已知限制）

## 背景

商城管理页的目录原本是「一行一条 + 右栏常驻详情」。两个问题在真实宿主里都能量出来：

1. **列宽不由视口决定。** 宿主管理侧栏可拖 14–22rem（SForum `apps/web/app/layouts/admin.vue`
   的 `min-size=14 / max-size=22 / default-size=16`），目录列宽跟着侧栏走。实测 1500 视口：
   16rem 侧栏时内容列 1195px（4 列），拉到 22rem 只剩 1099px（3 列）——同一个视口，`@media`
   断点给不出两个答案。
2. **详情常驻右栏吃掉一半目录宽度。** 安装条随右栏滚动，翻到第十条就看不见「装」在哪；
   而详情里真正需要常驻的只有「装哪个版本、装到哪」。

## 决定

1. **目录改卡片网格，列数用容器查询钉死。** `.sfstore` 上 `container-type: inline-size`，
   `@container` 1120 / 940 / 552 三档 → 4 / 3 / 2 / 1 列。理由：列数必须跟内容列走，
   视口断点会把「宽屏 + 22rem 侧栏」判成 4 列，实际只有 3 列宽。
2. **详情改挂 `document.body` 的居中弹窗，三 Tab（README / 版本信息 / 更新说明），底部
   64px 安装条常驻。** 理由：`.sfstore` 的 `container-type` 会成为 fixed 后代的包含块，
   弹窗留在页面根会被裁进内容列；安装条放弹窗底部而不是某个 Tab 里，任意 Tab 都能装。
3. **弹窗固定高 `height: min(88vh, 780px)`。** 理由：三个 Tab 内容长短差很大，高度随内容变
   会带着底部安装条上下跳，切 Tab 时手指要重新找按钮。
4. **安装语义一行未改：成功仍是「已暂存」，启用/信任在 core；旧宿主仍走签名链接。** 理由：
   「不代劳启用/信任」是仓级边界（AGENTS.md 边界 5），改版只换容器，不碰交接点。
5. **更新说明用纯文本 `pre-wrap`。** 理由：商城 `notes` 是 GitHub Release 原文，服务端渲染
   markdown 要跨仓改契约与 sanitize 策略，不在本轮范围。
   **（已于 2026-10-26 取代：** 契约新增 `notesHtml`，渲染复用 README 那条链路，
   见 `2026-10-26-release-notes-markdown.md`。**）**
6. **卡片徽标 5 个槽位，超出显示前 4 枚 + `+N`；「可更新」只由封面角标表达一次。** 理由：
   槽位钉死卡片高度，长徽标集不会把某张卡拉高；同一结论在徽标行重复会与「已安装 v…」
   抢同一个判决位。徽标整枚换行，不收缩成省略号（3 列下曾被压成「插…」「v…」）。
7. **新增派生变量 `--sfstore-accent-ink`（暗色取 `--sf-accent-dark`）。** 理由：`--sf-accent`
   在暗底实测 3.24:1，只配做实心填充；文字、描边、焦点环改用 ink 变体，宿主品牌 token 不动。

## 放弃的方案

- **视口断点（`@media`）定列数**：侧栏可拖，视口宽 ≠ 内容列宽，错判是常态。
- **常驻右栏 / 抽屉**：右栏吃掉目录宽度，安装条跟着内容滚走。
- **弹窗留在 `.sfstore` 根内**：被 `container-type` 的包含块裁切，遮罩盖不住页面。
- **弹窗写 URL（深链）**：管理页是宿主页面里的 component，路由所有权在宿主；这轮不引入
  第二种路由所有权。
- **服务端渲染 notes 的 markdown**：要跨仓改 `store-api` 契约与 sanitize 白名单，收益只是排版。
- **直接给 `--sf-accent` 提亮**：会改掉宿主的品牌 token 语义，影响所有扩展页。

## 代价与重开条件

- **CSS 只剩 77 B 余量**（`catalog.css` 20,403 / 门禁 20,480）。后续任何视觉增补必须先删
  等量样式；要真正扩预算，得改计划 §7.5 第 17 条并写明理由。
- **宿主 `UModal` 的 overlay/content 没有 z-index**（靠 DOM 顺序；见 `#build/ui/modal` 生成物
  `apps/web/.nuxt/ui/modal.ts`）。
  所以层级归宿主：确认弹窗固定 `z-[80]`（core 侧 `ADMIN_HOST_DIALOG_Z_INDEX`），插件遮罩保持 40，
  安装期间不再改写 z-index —— 曾经的「降到 0」已删除，不要再加回来。
- **焦点陷阱在 Bun 的 DOM 替身里测不了**：`focusables()` 用 `:not()` 复合选择器，替身不支持
  → 单测里天然 no-op，只能靠浏览器验收。重开条件：替身支持复合伪类，或改成显式 focusable 列表。
- **弹窗不写 URL**：没有深链，刷新回到目录；需要分享「某个产品的某个 Tab」时再谈。
- **版本表不列每版本资产文件**：安装条只装当前选中版本，逐版本文件清单是发布方视角。
- **弹窗头部不重复平台列表**：完整平台在安装条下拉里，头部只留名字/版本/摘要。
- **真机截图只覆盖 1331×948**：内置浏览器视口固定，1633×810 与 390×844 两档目前只有 CDP harness
  证据；换到能开窗的机器或内置浏览器支持改视口后补（见交接 Open Questions）。
